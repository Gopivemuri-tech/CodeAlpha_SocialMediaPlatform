# Local Test Checklist

Run the project, then verify these flows before submission:

1. Register User A and User B.
2. Log in as User A and create a text post.
3. Create a second post with an image URL.
4. Log in as User B and like User A's post.
5. Add a comment to User A's post.
6. Open User A's profile and follow them.
7. Confirm follower/following counts update correctly.
8. Search for a user from the navigation search box.
9. Edit your profile bio, location, and avatar URL.
10. Delete one of your own posts and confirm another user's post cannot be deleted by you.
11. Open `/admin/` and verify Profiles, Follows, Posts, Likes, and Comments are available.

If all steps pass, the CodeAlpha Task 2 functional requirements are covered.
